# Reflex

A typing trainer you just open and type in. A self-learning core (neural typist model +
planner) picks every line so practice goes where it pays off most.

Personal project. All rights reserved, see LICENSE.

Build: `./build.sh` (needs Rust via rustup and the Xcode Command Line Tools).

Adopted from the Keyglide prototype: see [ROADMAP.md](ROADMAP.md).
